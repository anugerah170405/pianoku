# Pianoku

A minimalist web piano for playing notes, learning simple songs, and exploring sheet music.

![Pianoku](https://raw.githubusercontent.com/anugerah170405/assets/main/assets/images/1791090421865_pianoku.png)

## About

Pianoku is a responsive web piano built with React and TypeScript.

You can play the piano using your mouse choose built-in sheet music, and play songs directly from the piano interface.

The project focuses on a simple, clean, and enjoyable experience for playing and practicing piano.

## Features

- 🎹 Play piano notes using mouse or keyboard
- 🎵 Play songs from built-in sheet music
- ▶️ Play, pause, resume, and stop sheet playback
- 📱 Responsive layout for desktop, tablet, and mobile
- 🔊 Multiple piano sound styles
- 🌙 Light and dark themes
- ⚙️ Customizable settings
- 🎨 Clean and minimal interface

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- Tone.js

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/anugerah170405/pianoku.git
```

Navigate to the project directory:

```bash
cd pianoku
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite, usually:

```text
http://localhost:5173
```
